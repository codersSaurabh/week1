# Personal Portfolio Website

A simple and responsive personal portfolio website built using **HTML, CSS, and Bootstrap**.

The website presents my profile, education, technical skills, projects, and contact information in a single-page layout.

## Features

* Responsive single-page portfolio
* Sticky navigation bar
* Smooth navigation between sections
* About Me section
* Education section
* Technical Skills section
* Projects section
* Contact form
* Responsive layout using Bootstrap
* Dark theme with gradient accents

## Sections

### About

Introduction about me, my role, and technical skills.

### Education

Displays my educational background.

### Projects

Showcases some of my development projects with their technologies.

### Contact

Simple contact form for visitors to get in touch.

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5

## How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder.

3. Open `index.html` in a browser.

No additional installation is required.
